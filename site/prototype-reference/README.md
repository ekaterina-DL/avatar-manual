# Референс утверждённого макета

> ⚠️ **`template.html` не открывать в браузере для просмотра** — там вместо настоящих
> картинок/видео/шрифтов текстовые плейсхолдеры (`__IMG_...`, `__VIDEO_...`), браузер честно
> покажет сломанные иконки вместо них. Это нормально: файл — эталон **CSS и вёрстки для
> копирования** в тему сайта, а не страница для просмотра.
>
> **Чтобы посмотреть, как это выглядит по-настоящему** (с реальным видео и картинками) —
> открой в браузере опубликованную ссылку:
> https://claude.ai/code/artifact/33ae6f48-0bc4-4d6a-b2ae-2eebf9c48664

Это код живого интерактивного макета, который мы делали и правили вместе (страница
«Сегменты», мануал 2 этапа) — сохранён сюда из временной папки сессии, чтобы не потерялся.

## Что здесь

- `template.html` — полный HTML/CSS/JS макета. Вместо реальных видео/картинок — плейсхолдеры
  вида `__VIDEO_FAST__`, `__IMG_EXAMPLE1__` (их подставляет `build.py` из сессии, здесь не
  нужен) — но вся вёрстка, все классы, весь CSS **настоящие и утверждённые**.
- `fonts/` — реальные файлы шрифтов (Golos Text, PT Serif; кириллица + латиница, только нужные
  начертания), уже выкачаны и подготовлены — не нужно заново лезть в Google Fonts и разбирать
  unicode-range.

## Как этим пользоваться при сборке сайта (Task 5 детального плана)

Не копировать `template.html` как есть — это одностраничный макет-демо, не MkDocs-тема. Нужно
**перенести классы/CSS-переменные** из `<style>` в `site/theme/extra.css`, адаптировав под
разметку, которую генерирует MkDocs Material.

### ⚠️ Важно: точные цвета отличаются от того, что уже написано в детальном плане

В `docs/superpowers/plans/2026-08-06-avatar-manual-site.md` (Task 5) акцентный цвет задан
приблизительно (`#C9852B`) — это не настоящее значение, а угадано по текстовому описанию
«тёплый янтарный акцент» (та сессия не имела доступа к этому макету). **Настоящие,
утверждённые значения — ниже, их и нужно использовать.**

### Настоящие цвета (проверенные на макете, светлая/тёмная тема)

```css
/* светлая тема */
--ink:        #1B2226;   /* основной текст */
--ink-soft:   #4B5760;   /* второстепенный текст */
--paper:      #F2F4F5;   /* фон страницы */
--surface:    #FFFFFF;   /* фон карточек */
--surface-2:  #EAEDEE;   /* фон подложек/бейджей */
--accent:     #B96A22;   /* акцент — тёплый янтарный */
--accent-ink: #8F5119;   /* акцент для текста (контрастнее) */
--good:       #2E7D4F;   /* «допустимо» */
--bad:        #B23B32;   /* «недопустимо» */

/* тёмная тема */
--ink:        #E7EAEA;
--ink-soft:   #A9B2B7;
--paper:      #14181B;
--surface:    #1A1F22;
--surface-2:  #20262A;
--accent:     #E0904A;
--accent-ink: #F2B27E;
--good:       #4EAE79;
--bad:        #E07268;
```

Полные значения (включая `rgba()` для фонов/рамок `-bg`/`-line`) — смотри `:root` в начале
`template.html`, строки 16–53.

### Шрифты

- **Golos Text** — заголовки, интерфейс, значки, метки. Начертания 500/600/700.
- **PT Serif** — основной текст. Начертания 400/700/400-italic.
- Файлы уже лежат в `fonts/` этой папки, подготовлены под кириллицу+латиницу отдельно (меньше
  вес, чем полный шрифт). В детальном плане сейчас шрифты подключены через `@import` с
  `fonts.googleapis.com` (CDN) — план сам помечает self-hosting шрифтов как отложенную
  задачу «Phase 2»; когда до неё дойдёт очередь, эти файлы уже готовы, повторно скачивать и
  разбирать unicode-range не нужно.

### Компоненты, которые уже реализованы и провалидированы в макете

Ищите в `template.html` по названию класса — CSS уже готов, разметку можно адаптировать:

| Компонент | Класс в CSS |
|---|---|
| Карточки-факты для ключевых цифр | `.keyfacts`, `.kf-stat`, `.kf-value`, `.kf-tags` |
| Значки по смыслу вместо точек списка | `.rules-list`, `.li-icon` (`.time` / `.forbid`) |
| Сетка примеров 3–4 в ряд | `.example-grid`, `.example-card` |
| Увеличение картинки по наведению | `.example-card:hover img`, `.compare-card:hover img` |
| Сравнение «Правильно/Неправильно» | `.compare`, `.compare-card.good` / `.bad` |
| Встроенный видео-плеер | `.video-block`, `.video-item` |

Все эти компоненты в детальном плане сознательно отложены на «Phase 2» (после публикации,
постранично) — когда до них дойдёт очередь, весь нужный CSS уже здесь, не с нуля.
