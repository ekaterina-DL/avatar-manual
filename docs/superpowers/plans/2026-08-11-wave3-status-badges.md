# Волна 3: статус-плашки в 09-disputed-points.md — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить текстовые строки «Статус: …» в `manual-2-etap/09-disputed-points.md` (17 пунктов) на цветные плашки 🟢/🟡/🔴 на сайте, сохранив весь текст пояснений 1:1 и не тронув PDF-профиль.

**Architecture:** Каждая строка «Статус: …» нормализуется к одному из 3 канонических жирных ярлыков (`**Решено**` / `**Частично решено**` / `**Не решено**`), после которого текст пояснения остаётся без изменений. Новый build-хук `site/hooks/build_status_badges.py` матчится по этому фиксированному словарю (regex на начало строки) и заменяет ярлык на `<span class="status-badge ...">`. CSS переиспользует уже существующие цветовые токены.

**Tech Stack:** mkdocs-material build hooks (Python, `on_page_markdown`), pytest, CSS (site/theme/extra.css).

## Global Constraints

- Все факты, даты, цитаты, ссылки внутри пояснений после ярлыка «Статус: …» переносятся 1:1 —
  меняется только вступительная фраза (см. Addendum от 11.08.2026 в
  `docs/superpowers/specs/2026-08-11-stage2-dedup-design.md` — там же полная таблица
  классификации всех 17 пунктов).
- Классификация: 🟢 Решено / 🟡 Частично решено / 🔴 Не решено — точные значения для каждого из
  17 пунктов заданы в таблице ниже (Задача 1, Шаг 2), отклоняться нельзя.
- Заголовки разделов (`### ...`, включая `⚠️ НОВОЕ`, `[РЕШЕНО]`, `⚠️ РЕШЕНО`) не трогать вообще —
  риск сломать якоря (`#...`), на которые ссылаются другие файлы.
- Хук — только сайт: PDF-профиль (`is_pdf_build(config)` из `_build_profile.py`) должен получать
  markdown без изменений (то есть чистый текст «Статус: **Решено** — ...» без HTML).
- Хук матчится по фиксированному словарю (regex на начало строки `^- Статус: \*\*(Решено|Частично решено|Не решено)\*\*`),
  не по произвольному тексту — устойчиво к будущим правкам прозы (принцип уже применялся в
  `build_dispute_flow.py`/`build_compare_cards.py`).
- Цвета — переиспользовать существующие CSS-переменные: `--ok-color`/`--ok-bg` (🟢),
  `--no-color`/`--no-bg` (🔴), `--accent-ink`/`--accent-bg` (🟡). Новых CSS-переменных не вводить.

class FakeFile:
    def __init__(self, src_uri):
        self.src_uri = src_uri


class FakePage:
    def __init__(self, src_uri):
        self.file = FakeFile(src_uri)


class FakeSiteDir:
    def __init__(self, value):
        self._value = value

    def __str__(self):
        return self._value


class FakeConfig(dict):
    def __init__(self, site_dir):
        super().__init__()
        self.site_dir = FakeSiteDir(site_dir)

- [ ] **Шаг 3: Создать `site/hooks/build_status_badges.py`**

```python
import re

from _build_profile import is_pdf_build

_STATUS_RE = re.compile(
    r"^- Статус: \*\*(Решено|Частично решено|Не решено)\*\*",
    re.M,
)

_BADGE_CLASS = {
    "Решено": "status-ok",
    "Частично решено": "status-partial",
    "Не решено": "status-open",
}

_BADGE_EMOJI = {
    "Решено": "🟢",
    "Частично решено": "🟡",
    "Не решено": "🔴",
}


def _render(match):
    label = match.group(1)
    css_class = _BADGE_CLASS[label]
    emoji = _BADGE_EMOJI[label]
    return f'- <span class="status-badge {css_class}">{emoji} {label}</span>'


def on_page_markdown(markdown, page, config, files):
    """Строка "- Статус: **Решено**/**Частично решено**/**Не решено**" (канонический словарь,
    см. шапку manual-2-etap/09-disputed-points.md, "Формат записи") превращается в цветную
    плашку. Матчит только сам ярлык в начале строки — текст пояснения после него (факты, даты,
    ссылки, цитаты) не трогает. Вложенные упоминания "Статус:" не в начале bullet-а (например,
    внутри абзаца про точную границу 10:00 в разделе про макс. длину видео) не матчатся — regex
    заякорен на начало строки через re.M. PDF-профиль не трогаем: там остаётся обычный текст."""
    if is_pdf_build(config):
        return markdown
    if page.file.src_uri.replace("\\", "/") != "manual-2-etap/09-disputed-points.md":
        return markdown
    return _STATUS_RE.sub(_render, markdown)
```
