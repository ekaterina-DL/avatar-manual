# Проект «Аватар» — обучение асессоров

База знаний разделена на два независимых мануала — по числу этапов проекта, у которых разные
классификаторы и частично разные правила разметки. Не путайте их между собой.

## Структура

- **[manual-2-etap/](manual-2-etap/00-overview.md)** — мануал по **2 этапу** (заявки 26, 27, 28).
  Асессор ищет подходящий сегмент (10–300 сек) внутри длинного сырого видео.
- **[manual-3-etap/](manual-3-etap/00-overview.md)** — мануал по **3 этапу** (заявка 46).
  Асессор оценивает уже нарезанный фрагмент целиком, без внутреннего поиска сегмента. Свой,
  более крупный классификатор (19 вопросов вместо ~14).
- **[_raw-sources/](_raw-sources/)** — исходные материалы (PDF/XLSX), из которых собраны оба
  мануала, разложены по трём папкам:
  - `2-etap/` — материалы только по 2 этапу;
  - `3-etap/` — материалы только по 3 этапу;
  - `both-stages/` — материалы, где вперемешку встречается информация по обоим этапам
    (например, сквозная переписка в Telegram с самого начала проекта, или внутренний чат
    исполнителей, где команда переключалась между этапами).

Каждый мануал ведёт собственный журнал источников (`_sources-log.md`), где по каждому файлу
из `_raw-sources/` указано, что именно из него было извлечено и куда внесено.

## С чего начать

Прочитайте `00-overview.md` в мануале нужного этапа — там объяснены цели проекта, ключевые
отличия от другого этапа и ссылки на остальные разделы мануала.
